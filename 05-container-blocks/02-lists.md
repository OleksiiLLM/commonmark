# 5. Container Blocks: Lists and List Items

## List Markers
- **Bullet lists**: Use `-`, `+`, or `*`.
- **Ordered lists**: Use a sequence of 1-9 digits followed by `.` or `)`.

## List Items
Items must be indented according to the width of the list marker and its following space to be considered part of the list item.

### Example
```markdown
1.  A paragraph
    with two lines.

        indented code

    > A block quote.
```

Lists can be **tight** (no blank lines between items) or **loose** (blank lines between items, forcing `<p>` tags around content).
