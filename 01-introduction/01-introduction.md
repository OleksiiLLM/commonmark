# 1. Introduction

## What is Markdown?
Markdown is a plain text format for writing structured documents, based on conventions for indicating formatting in email and usenet posts. Its distinguishing feature is its readability; it is designed to be publishable as plain text.

## Why is a spec needed?
The original description of Markdown's syntax did not specify the syntax unambiguously. A spec was needed to address inconsistencies in how parsers handled edge cases like sublist indentation, blank lines, and nested formatting.
