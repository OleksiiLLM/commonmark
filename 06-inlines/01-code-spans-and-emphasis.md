# 6. Inlines: Code Spans and Emphasis

## Code Spans
A code span begins with a backtick string and ends with a backtick string of equal length.
```markdown
Use the `printf` function.

``You can include literal backticks ` if you use double backticks.``
```

## Emphasis and Strong Emphasis
- **Emphasis**: Enclosed in single `*` or `_`.
- **Strong Emphasis**: Enclosed in double `**` or `__`.

### Example
```markdown
*Emphasis* and **Strong Emphasis**
```
