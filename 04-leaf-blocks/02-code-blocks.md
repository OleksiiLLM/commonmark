# 4. Leaf Blocks: Code Blocks

## Indented Code Blocks
A sequence of non-blank lines, each preceded by four or more spaces of indentation.
```markdown
    a simple
      indented code block
```

## Fenced Code Blocks
Begins with a code fence (three or more backticks ` ``` ` or tildes `~~~`). You can also specify an info string (e.g., a language) next to the opening fence.
```markdown
~~~python
def foo(x):
  return 3
~~~
```
